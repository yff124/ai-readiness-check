# 企业 AI 落地诊断器 · AI Readiness Check

一个纯前端的自测工具：勾选你公司**正在重复做**的那几类工作，算出——**最该先上 AI 的三个环节**、每月能省下多少工时、折合多少人力成本、以及第一个环节的回本周期。

**所有计算在你本地浏览器完成，不收集、不上传任何数据。无后端，无追踪，无依赖。**

## 在线使用

https://yff124.github.io/ai-readiness-check/

## 它想纠正的一个顺序错误

中小公司做 AI 落地，最常见的顺序是：

> 先买一个工具 → 再招一个"会用 AI 的人" → 等三个月看效果。

而这个顺序恰好是反的。因为**你还没回答那个真正的问题——你公司现在最耗人的是哪件事。**

这个工具用三个指标帮你排序：

| 指标 | 含义 |
|---|---|
| **频次** | 这类事每周全公司一共花掉多少小时 |
| **可替代比例** | 这类事通常有多大比例能被 AI 接手 |
| **落地周期** | 从开始做到真正切换过去，大概几天 |

三项综合下来排在最前面的，就是该先动的那个环节。**先做一个，做成了再动第二个** —— 一次性铺开五个，通常五个都做不成。

内置 23 类常见工作，覆盖内容与市场、电商与门店、销售、客服与运营、行政与人事、通用事务。

## 本地运行

单文件、零依赖。直接双击 `index.html`，或在目录里起一个静态服务：

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000

## 说明

结果基于通用经验值估算，用于**判断优先级**，不等同于对某家公司的正式评估。不承诺任何具体收益。
